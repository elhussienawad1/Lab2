# Lab 34

This lab covers two topics:

- **Bayes classification:** estimate likelihoods using kernel density estimation (KDE).
- **Principal Component Analysis (PCA).**

## Where to start

1. Read `KDEstimator.ipynb`, implement `KDEstimator.py`, then return to the notebook tests.
2. Read `BayesClassifier.ipynb` and implement `BayesClassifier.py`. This topic builds on KDE.
3. Read `PCA.ipynb`, implement `PCA.py`, then run the notebook tests.
4. Finish with `Microbiologist.ipynb` for a Bayes classification application.
